# Privacy

VillaPro stores villa, guest, booking, invoice, payment, media, and business
profile data locally on the user's device. The application does not include
analytics, advertising, account tracking, or an application-operated cloud
service.

Android system backup is disabled for application data. Fonts are bundled in
the application and are not downloaded at runtime.

Data leaves the application only when the user explicitly shares customer
content or saves a backup. Backups include personal and financial information
and are encrypted with a password selected by the user. Losing that password
makes the backup unrecoverable.

VillaPro may request notification access to show booking and unpaid-invoice
reminders. Notification content can be visible on the device lock screen,
depending on system settings.
